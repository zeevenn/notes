## 放置规则

- 语言语法、语义、类型系统和标准库放在对应语言目录。

- 浏览器 API、前端框架、服务端框架和数据库等内容按应用领域归类。
- 一篇笔记只保留一个主要位置，其他学习路径通过相对链接和 frontmatter 标签建立关联。
